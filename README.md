# 厚粲杯 · AIGC 绿色消费实验 Agent

本项目包含 **12 个实验 Agent**，用于「厚粲杯」心理与认知智能测评挑战赛的线上实验，
模拟自助支付界面的人机对话，干预被试的绿色消费选择。

## 实验设计

- **组别（2 水平）**：协作规范诉求组（协作组）/ 非协作规范诉求组（非协作组）
- **品类（6 类）**：笔类、包装胶带、垃圾袋、牙刷、纸杯、纸张
- 每个品类 × 每个组别 = 1 个 Agent，共 **12 个**

每个品类 Agent 内置**该品类的普通款与环保可降解款两类商品信息**
（外观描述 + 价格），例如「笔类」同时包含「金属中性笔（普通款 5.68 元）」
与「咖啡渣环保中性笔（环保可降解款 10.00 元）」。

协作组与非协作组仅在**干预文案的关键词**上区分：

| 组别 | 核心操纵句 | 关键词 |
| --- | --- | --- |
| 协作组 | 加入我们，让我们一起为环保做出贡献！ | 加入我们 / 一起 / 共同 / 我们 |
| 非协作组 | 请选择绿色消费！ | 请选择 / 您 / 个人 |

## 行为逻辑

| 被试输入 | Agent 回复 |
| --- | --- |
| 本品类普通商品（如「金属中性笔」） | 「本店有两种笔售卖：」+ A/B 外观/价格 + 干预文案 |
| 环保款商品（如「咖啡渣环保中性笔」「竹牙刷」） | 「本次请输入普通版本商品，请重新输入对应普通商品名称。」 |
| 本品类以外的商品（如「键盘」） | 「抱歉，暂不支持该商品，请输入与笔有关的商品。」（按品类定制） |
| 追问（优点/好处/缺点/用途/价格/安全/耐用/对比/推荐/环保概念） | 从 A/B 知识库回答，12 个 agent 风格统一 |

开场欢迎语（固定）：
> 顾客您好！欢迎光临小林超市，我是本店的 AI 智能助手小林，请输入您的商品信息。

### 追问示例（以「笔类」为例）

- 输入「金属中性笔的优点」 → 「A（金属中性笔）的优点：不锈钢金属笔杆，坚固耐用；……」
- 输入「B的缺点」 → 「B（咖啡渣环保中性笔）的缺点：颜色以咖啡色系为主……」
- 输入「多少钱」 → 同时列出 A、B 价格
- 输入「哪个好」 → A/B 对比 + 引导语
- 输入「推荐哪个」 → 推荐 + 引导语

> 每个回答末尾会附组别引导语（协作组「加入我们，让我们一起选择…」；非协作组「请您选择…」）。

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `agents/` | 标准版 Agent（含 `<script>` 标签，本地直接打开即可测试） |
| `agents_iframe/` | 见数版：内层 HTML 用 base64 编码嵌入 iframe，隐藏 script/style 标签 |
| `agents_noscript/` | 见数版：零 `<script>` 标签，JS 经 base64 + `<body onload>` 执行 |

| `wrap_iframe.py` / `wrap_noscript.py` | 生成两种见数兼容版本 |

## 上传见数（Credamo）的方法

1. 在见数平台创建「Web 问卷 / iframe 嵌入」题目；
2. 若平台支持 iframe 嵌入：使用 `agents_iframe/` 中的 HTML；
3. 若平台屏蔽 `<script>` 标签：使用 `agents_noscript/` 中的 HTML；
4. 将对应 HTML 内容粘贴 / 以 URL 方式嵌入题目即可。

Agent 会通过 `postMessage` 上报 `session_init` / `user_input` / `product_response` /
`eco_product_prompt` / `qa_response` / `error_response` 等事件，可在宿主页面监听
`green_consumption_experiment` 来源的消息，或在页面内调用 `window.getExperimentData()` 获取交互日志。

## 重新生成

```bash
python3 generate_agents.py   # 生成 agents/
python3 wrap_iframe.py       # 生成 agents_iframe/
python3 wrap_noscript.py     # 生成 agents_noscript/
```
