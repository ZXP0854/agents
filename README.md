# 厚粲杯 · AIGC 绿色消费实验 Agent

本项目包含 **12 个实验 Agent**，用于「厚粲杯」心理与认知智能测评挑战赛的线上实验，
模拟自助支付界面的人机对话，干预被试的绿色消费选择。

## 实验设计

- **组别（2 水平）**：协作规范诉求组（协作组）/ 非协作规范诉求组（非协作组）
- **商品（6 个）**：A4白纸、一次性纸杯、金属中性笔、透明胶带大卷、垃圾袋、软毛牙刷
- 每个商品 × 每个组别 = 1 个 Agent，共 **12 个**

每个 Agent 内置**该商品的非环保款（A）与环保款（B）两类商品信息**
（外观描述 + 价格），例如「金属中性笔」同时包含「金属中性笔（非环保产品 5.68 元）」
与「咖啡渣环保中性笔（环保产品 10.00 元）」。

协作组与非协作组仅在**干预文案的关键词**上区分：

| 组别 | 核心操纵句 | 关键词 |
| --- | --- | --- |
| 协作组 | 加入我们，让我们一起为环保做出贡献！ | 加入我们 / 一起 / 共同 / 我们 |
| 非协作组 | 请选择绿色消费！ | 请选择 / 您 / 个人 |

## 两轮交互流程

输入框灰字随流程切换：

| 轮次 | 灰字 | 被试操作 | Agent 回复 |
| --- | --- | --- | --- |
| 第一轮 | 请输入产品名称 | 输入本品类普通商品（差一两个字、意思一致也可，如「中性笔」「白纸」） | 核心操纵文案（干预文案） |
| 第二轮 | 您可以询问环保类型商品的优势信息 | 自由追问 / 询问商品 / 询问优势 | 环保款优势、优缺点、价格、材质、外观、对比、推荐等问答（重点突出环保款区别与优势，不罗列 A/B 编号） |

> 第一轮只有输入正确商品才进入第二轮；输入错误时提示并停留。

| 错误情况 | Agent 回复 |
| --- | --- |
| 输入错误商品 | 「抱歉，未检索到当前商品，请输入正确的商品。」 |
| 输入环保款商品 | 「抱歉，未检索到当前商品，请输入正确的商品。」 |
| 词库未覆盖的追问 | 「关于这个问题我暂时没有更多信息。您可以向我询问环保类型商品的优势信息，或商品的优缺点、价格、材质、使用等具体信息。」 |

开场欢迎语（固定）：
> 顾客您好！欢迎光临小林超市，我是本店的 AI 智能助手小林，请输入您的商品信息。

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `agents/` | 标准版 Agent（含 `<script>` 标签，本地直接打开即可测试） |
| `agents_iframe/` | 见数版：内层 HTML 用 base64 编码嵌入 iframe，隐藏 script/style 标签 |
| `agents_noscript/` | 见数版：零 `<script>` 标签，JS 经 base64 + `<body onload>` 执行 |
| `generate_agents.py` | 一键重新生成 12 个 Agent |
| `wrap_iframe.py` / `wrap_noscript.py` | 生成两种见数兼容版本 |

## 上传见数（Credamo）的方法

1. 在见数平台创建「Web 问卷 / iframe 嵌入」题目；
2. 若平台支持 iframe 嵌入：使用 `agents_iframe/` 中的 HTML；
3. 若平台屏蔽 `<script>` 标签：使用 `agents_noscript/` 中的 HTML；
4. 将对应 HTML 内容粘贴 / 以 URL 方式嵌入题目即可。

Agent 会通过 `postMessage` 上报 `session_init` / `user_input` / `product_copy` /
`product_info` / `qa_response` / `eco_product_prompt` / `error_response` 等事件，
可在宿主页面监听 `green_consumption_experiment` 来源的消息，或在页面内调用
`window.getExperimentData()` 获取交互日志。

## 重新生成

```bash
python3 generate_agents.py   # 生成 agents/
python3 wrap_iframe.py       # 生成 agents_iframe/
python3 wrap_noscript.py     # 生成 agents_noscript/
```
